# 🛡️ Модуль безопасности и защиты (core-security)

## Назначение
Модуль обеспечивает комплексную эшелонированную защиту Android и JVM приложений экосистемы от:
- Статического анализа, декомпиляции (JADX, Ghidra, Apktool) и вытягивания строк через `strings`.
- Атак класса "Человек посередине" (Man-in-the-Middle) при передаче данных через публичные туннели.
- Перебора ответов, DoS-атак и попыток фальсификации результатов тестирования.

---

## Компоненты модуля

### 1. `SessionCrypto` — Сессионное шифрование
Реализует гибридную криптографическую схему:
1. **Генерация эфемерной пары RSA-2048**:
   - При старте сессии генерируется уникальная в памяти пара ключей.
   - Публичный ключ экспортируется в формате Base64 SPKI (`getPublicKeyBase64()`) и передается веб-клиенту в hash-части URL (`#key=...`), что исключает его логирование на промежуточных proxy-серверах.
2. **Расшифровка ответов RSA-OAEP (SHA-256 + MGF1)**:
   - Клиентский браузер (через нативный Web Crypto API) шифрует ответ публичным ключом сервера.
   - Сервер расшифровывает ответ приватным ключом. Никакие пароли или общие секреты не утекают в сеть.
3. **Симметричное шифрование AES-GCM-256**:
   - Используется 256-битный сессионный ключ.
   - Для **каждого пакета** генерируется уникальный криптографически стойкий 12-байтный одноразовый вектор инициализации (IV/Nonce).
   - Защита от модификации и подделки пакетов за счет встроенного 128-битного аутентификационного тега GCM.
4. **HMAC-SHA256 с защитой от тайминг-атак**:
   - Проверка цифровых подписей выполняется через `MessageDigest.isEqual()`, работающий за константное время, что предотвращает атаки по времени (Timing Side-Channel Attacks).

```kotlin
val crypto = SessionCrypto()
val publicKey = crypto.getPublicKeyBase64() // Отправляем клиенту

// Шифрование данных:
val encrypted = crypto.encryptAesGcm("секретные данные")
val decrypted = crypto.decryptAesGcm(encrypted)
```

### 2. `SecureStringMask` — Обфускация секретов и эндпоинтов
Утилита предотвращает извлечение URL, API-токенов и системных путей при простом поиске по бинарнику (`strings app.apk`):
- Применяет динамическое XOR-маскирование со смещением по индексу `(key xor (i % 37))` и Base64 упаковку.
- Демаскирование происходит «на лету» (Just-in-Time) исключительно в момент обращения в оперативной памяти.

```kotlin
// Маскирование константы при разработке:
val masked = SecureStringMask.mask("https://api.internal.service/v1")

// Использование в коде:
val endpoint = SecureStringMask.demask(masked)
```

### 3. `RateLimiter` — Защита от DoS и брутфорса
Потокобезопасный ограничитель на базе скользящего секундного окна и `ConcurrentHashMap`:
- Отслеживает число запросов с каждого IP-адреса или токена клиента.
- Автоматически вытесняет устаревшие записи, предотвращая переполнение оперативной памяти (OOM) на мобильном устройстве.

```kotlin
val limiter = RateLimiter(maxRequestsPerSecond = 10)

if (!limiter.isAllowed(clientIp)) {
    // Возвращаем HTTP 429 Too Many Requests
}
```

## Правила обфускации ProGuard / R8
Всегда используйте файл `templates/proguard-rules.pro` в ваших приложениях. Он включает агрессивную перегрузку имен методов, сплющивание пакетов (`repackageclasses`) и удаление отладочных логов в релизных сборках.
