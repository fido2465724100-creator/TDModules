# 📦 TDModules — Единый каталог универсальных модулей экосистемы
> **Версия библиотеки:** `v1.3.2` | **Репозиторий:** [github.com/fido2465724100-creator/TDModules](https://github.com/fido2465724100-creator/TDModules)  
> **Целевые проекты:** `Tdroid`, `UniTest`, `TDnetScript`, `TDRobotics`, `SuperDriver`, `Drlmstudio`, `AIDream`

**TDModules** — это модульный архитектурный центр, объединяющий готовые, протестированные и не зависящие от внешних платных серверов ($0 Infrastructure) компоненты. Модули написаны на чистом **Kotlin JVM**, не привязаны к тяжелым фреймворкам и работают на смартфонах, микрокомпьютерах, роботах и десктопах.

## 🔍 Детальный обзор каждого модуля

### 1. `core-localization` — Глобальная локализация (109 языков)
**Проблема, которую решает:** Устраняет хардкод строк и необходимость писать свои кривые парсеры переводов в каждом приложении.
- **`LocaleRegistry`**: Полный реестр 109 языков стандарта ISO 639-1 (самоназвания: *Deutsch*, *Español*, *Русский*, *العربية* и т.д.), признак письма справа-налево (`isRtl`).
- **`LocalizationEngine`**: 
  - Гарантирует, что приложение **никогда не покажет пустой экран или краш** из-за отсутствующего перевода: работает цепочка фоллбеков (`Выбранный язык` → `Английский (EN)` → `Имя ключа`).
  - Ленивая загрузка: словарь загружается в память только при фактическом выборе языка.
  - Поддержка параметров (`%s`, `%d`, `{key}`) и реактивных слушателей (`addOnLanguageChangeListener`).
- **`CommonKeys` и `BuiltinTranslations`**: Вшитые базовые переводы для типовых кнопок (*ОК*, *Отмена*, *Сохранить*, *Назад*, *Ошибка*).

---

### 2. `core-education` — Мультиязычное образование, тесты и словарные движки
**Проблема, которую решает:** Решает проблему полиглотов и врачей: добавление новых языков без потери многолетней истории интервального повторения, а также адаптация тестов под любой язык на лету.
- **Concept-Pivot Model (`ConceptTermModels.kt`)**: 
  - Термин привязывается к семантическому концепту и международному английскому якорю (`englishAnchor`).
  - Прогресс запоминания по алгоритму **SuperMemo SM-2** (`intervalDays`, `easeFactor`, `repetitions`, `correctCount`, `wrongCount`) ведется раздельно для каждого языка изучения.
- **`DynamicContentTranslator.kt`**: 
  - Динамический доперевод вопросов, вариантов ответов и медицинских определений на лету под язык интерфейса с кэшированием.
- **Режим сопоставления пар (`Matching Pairs`)**:
  - Модели `MatchingPairItem`, `MatchingRoundState` и канонические константы анимаций (`MatchingSessionConstants`: задержка 180 мс, исчезновение 320 мс, скейл 0.82) — единый стандарт карточных игр для `AIDream` и `UniTest`.
- **Полиморфные тесты (`PolymorphicQuizModels.kt`)**:
  - Вопрос хранит инвариантные ключи ответов (`correctOptionKey`). Студент может прямо в процессе теста переключить язык с немецкого на английский или русский — тест не собьется, а варианты ответов корректно перемешаются.
- **`UnifiedEducationalParser.kt`**:
  - «Всеядный» парсер: распознает двухколоночный текст (`::`, `\t`, ` - `, ` | `), тесты с маркерами (`*`, `+`, `[x]`, `1)`, `A)`), формат Anki TSV/CSV и сам генерирует правдоподобные дистракторы (неправильные варианты).

---

### 3. `core-tdscript` — Встраиваемый язык сценариев (0 KB VRAM)
**Проблема, которую решает:** Единый детерминированный язык сценариев для автоматизации, работающий абсолютно одинаково в текстовом терминале телефона (`Tdroid`), промышленном контроллере Modbus (`TDnetScript`) и робототехнике (`TDRobotics`).
- **Headless / 0 KB VRAM**: В ядре нет ни одной графической зависимости. Вывод направляется в символьный матричный буфер TUI или консоль.
- **Архитектура ядра**: Полноценный конвейер `Lexer -> Parser -> AST -> Interpreter` по спецификации `SPEC-TDS-CORE-1.0.1`. Поддерживает переменные (`let`/`var`), условия, циклы `while`, строгую типизацию и защиту от зависаний.
- **Эшелонированные права (`Capabilities`)**: Битовая маска безопасности (`NET_READ`, `NET_SCAN`, `PLC_READ`, `PLC_WRITE`, `BT_ACCESS`, `HARDWARE`, `UI_CORE`, `BACKGROUND`). Скрипт не сможет открыть сокет или включить реле без явного разрешения хоста.
- **Абстракция платформы (`HostSPI`)**: Нормативный контракт для периферии: управление Bluetooth BLE/SPP, Modbus TCP/RTU, пинг, HTTP-запросы, вибрация, системные алерты и прямые запросы к ИИ (`aiAsk`).

---

### 4. `core-security` — Нулевые затраты на сервер ($0) и криптозащита
**Проблема, которую решает:** Защита мобильного сервера (например, телефона преподавателя в `UniTest`) от перехвата ответов, DoS-атак и реверс-инжиниринга без покупки SSL-сертификатов.
- **`SessionCrypto.kt`**:
  - Сессионный **AES-GCM-256**: уникальный 12-байтный одноразовый вектор инициализации (IV/Nonce) генерируется криптостойким генератором на **каждый отдельный пакет**.
  - **RSA-OAEP 2048**: передача открытого ключа в URL Hash (`#key=...`) без отправки на сервер — браузер ученика шифрует ответ на лету через встроенный Web Crypto API.
  - **HMAC-SHA256**: проверка целостности с защитой от атак по времени (`MessageDigest.isEqual`).
  - Генерация криптографических токенов сессий с солью.
- **`SecureStringMask.kt`**: Динамическое маскирование строк и эндпоинтов (XOR + Base64), защищающее ключи и URL от статического анализа в `strings`, JADX и Ghidra.
- **`RateLimiter.kt`**: Потокобезопасный ограничитель частоты запросов с защитой от атак типа «отказ в обслуживании» (Anti-DoS) и автоматической очисткой устаревших IP для защиты памяти слабых устройств.

---

### 5. `core-network` — Отказоустойчивые туннели и авто-коннект
**Проблема, которую решает:** Публикация локального сервиса (веб-панели, экзаменационного сервера, робота) в глобальный интернет без белого IP, роутерных пробросов портов и платных подписок.
- **`TunnelManager.kt`**:
  - Ротация через пул **6 бесплатных обратных SSH-шлюзов**: `localhost.run`, `pinggy.io`, `serveo.net`, `telebit.cloud`, `bore.pub`, Cloudflare Quick Tunnel.
  - Автоматический приоритет прямого соединения (**Direct LAN**): если клиент находится в одной Wi-Fi сети с сервером, трафик идет напрямую без интернета.
  - **Active Socket Heartbeat**: 20-секундный сокетный пульс для раннего выявления «тихих» обрывов связи мобильных операторов.
  - Экспоненциальный откат (Exponential Backoff) со случайным джиттером (Jitter) при переподключении.
- **`NetworkUtils.kt`**: Интеллектуальное определение локального IP-адреса устройства с приоритетом точек доступа (Wi-Fi AP, wlan0, Ethernet, USB-модем).

---

### 6. `core-ai` — Бесплатный пул нейросетей и профилировщик «железа»
**Проблема, которую решает:** Встраивание функций генеративного интеллекта в проекты с $0 затратами на токены и подбор оптимальных локальных моделей.
- **`FreeModelPool.kt`**:
  - Бесшовная ротация бесплатных нейросетевых нод (`gpt-oss-120b`, `Meta-Llama-3.3-70B`, `openai-fast`).
  - Мониторинг доступности серверов: отслеживание ошибок 429 (Rate Limit) и 502/503 с обработкой заголовка `Retry-After` и автоматическим кулдауном сбойных узлов.
- **`PromptSanitizer.kt`**: Защитный шлюз: нейтрализация попыток взлома промптов (Jailbreak, Prompt Injection), обрезка системных управляющих тегов и защита от утечки инструкций.
- **`DeviceProfiler.kt`**:
  - Кроссплатформенный анализатор аппаратных ресурсов устройства (ОЗУ, свободная память, ядра CPU, архитектура ARM/x86, определение модели чипсета `socModel`).
  - Формирование точных рекомендаций по запуску локальных GGUF-моделей (1.5B, 3B, 7B) без риска падения приложения по OOM (Out of Memory).

## 🛠️ Как это подключается в проектах

Благодаря модульности, каждый проект берет **только то, что ему необходимо**.

В `settings.gradle.kts` целевого проекта (через `includeBuild`):
```kotlin
includeBuild("../TDModules") {
    dependencySubstitution {
        substitute(module("com.tdmodules:core-localization")).using(project(":core-localization"))
        substitute(module("com.tdmodules:core-security")).using(project(":core-security"))
        substitute(module("com.tdmodules:core-network")).using(project(":core-network"))
        substitute(module("com.tdmodules:core-ai")).using(project(":core-ai"))
        substitute(module("com.tdmodules:core-education")).using(project(":core-education"))
        substitute(module("com.tdmodules:core-tdscript")).using(project(":core-tdscript"))
    }
}
```

В `build.gradle.kts` модуля приложения:
```kotlin
dependencies {
    // Подключайте только то, что нужно конкретно вашему приложению:
    implementation("com.tdmodules:core-localization")
    implementation("com.tdmodules:core-security")
    implementation("com.tdmodules:core-network")
    implementation("com.tdmodules:core-ai")
    implementation("com.tdmodules:core-education")
    implementation("com.tdmodules:core-tdscript")
}
```

## 🔒 Стандарты надежности и регламент
1. **SemVer & Zero-Breakage**: Все релизы строго обратно совместимы. Старые срезы неизменяемо сохраняются в `releases/vX.Y.Z/`.
2. **Pre-commit Testing Gate**: Ни один коммит не попадает в репозиторий без 100% успешного прохождения автоматических тестов (`./gradlew test`).
3. **Безопасность ProGuard/R8**: Включены готовые правила защиты публичных интерфейсов и обфускации.
4. **Резервирование**: Полная синхронизация с защищенным приватным GitHub-репозиторием.
