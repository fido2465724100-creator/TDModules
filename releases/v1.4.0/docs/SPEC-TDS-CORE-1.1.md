# 📜 SPEC-TDS-CORE-1.1 — Нормативная спецификация языка TDscript Core 1.1

## 1. Введение и обратная совместимость
TDscript Core 1.1 развивает спецификацию 1.0.1, сохраняя 100% обратную совместимость со старыми скриптами.
Базовые принципы остаются неизменными:
* **0 KB VRAM / Headless**: ядро не зависит от графических подсистем и выполняется в детерминированном окружении.
* **Детерминизм вычислений**: однородный результат исполнения при одинаковом состоянии памяти.
* **Single Symbol Table**: единое плоское глобальное пространство видимости скрипта.

## 2. Директива локализации и Unicode-токенизация (`language: <code>;`)

### 2.1 Синтаксис директивы
Файл скрипта может начинаться с необязательной директивы языка:
```tdscript
language: ru;
пусть температура = 25;
если (температура > 20) {
    печать("Внимание: если температура поднимется, пусть включится охлаждение");
}
```

### 2.2 Правило токенизации (Lexer-Level Keyword Mapping)
> **КРИТИЧЕСКИ ВАЖНО**: Запрещена замена ключевых слов через глобальный `Regex.replace` по исходному тексту!
Ключевые слова на национальных языках (русский, немецкий, испанский и др.) распознаются **исключительно на этапе токенизатора (`Lexer`)**:
1. Лексер считывает Unicode-идентификатор `[A-Za-zА-Яа-яЁё0-9_]+`.
2. Если активен язык, отличный от `en`, лексер сверяет нормализованный идентификатор с таблицей ключевых слов языка:
   - `если` -> `TokenType.IF`
   - `иначе` -> `TokenType.ELSE`
   - `пока` -> `TokenType.WHILE`
   - `пусть`, `перем` -> `TokenType.LET` / `TokenType.VAR`
   - `истина` -> `TokenType.BOOLEAN (true)`
   - `ложь` -> `TokenType.BOOLEAN (false)`
   - `пусто` -> `TokenType.NULL`
3. Строковые литералы `"..."` и однострочные/многострочные комментарии `//`, `#`, `/* ... */` сканируются отдельно и **никогда не подвергаются подмене**, сохраняя исходный текст без искажений.

## 3. Локализованные строки (`lstring`) и бинарная таблица `I18N_TABLE`

### 3.1 Литерал `L"..."` и тип `lstring`
Для прикладных программ и интерфейсов оператора вводится тип `lstring`:
```tdscript
let msg = L"MSG_DOOR_OPEN:Door is open for {duration} seconds";
```
* **Запрет конкатенации**: Операции `L"..." + L"..."` или `L"..." + string` вызывают ошибку компиляции `TDS_E105_LSTRING_CONCAT_PROHIBITED`. Конкатенация запрещена, так как разрушает порядок слов и падежные согласования при переводе на 109 языков.
* **Форматирование**: Подстановка параметров осуществляется исключительно через именованные аргументы или метод форматирования:
  ```tdscript
  let alert = L"ALERT_TEMP_HIGH".format({"temp": 45, "sensor": "BME280"});
  ```

### 3.2 Трехступенчатый резолвинг при компиляции в `.tbc`
1. **Шаг 1 (Встроенная база)**: Проверка в `core-localization/BuiltinTranslations` (0 мс, оффлайн).
2. **Шаг 2 (Локальный кэш)**: Поиск в файле блокировки `tdscript.i18n.lock`.
3. **Шаг 3 (Нейросетевая генерация)**: Пакетный запрос к `core-ai/FreeModelPool` для генерации недостающих локализаций из 109 языков ISO 639-1.
Скомпилированные строки упаковываются в секцию `I18N_TABLE` контейнера `.tbc`.

## 4. Контроль безопасности выполнения (Fail-Safe VM Limits)
* **Call Stack Limit**: Максимальная глубина стека вызовов функций — **128 фреймов** (защита от переполнения стека).
* **Execution Step Limit**: Максимум **10 000 000 инструкций** на один цикл выполнения (защита от бесконечных циклов без ожидания).
* **Memory Quota**: Лимит динамических коллекций (массивы, словари) — не более **16 МБ** на песочницу.
